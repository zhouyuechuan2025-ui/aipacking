# 分镜获批后的动效细化

在同一张分镜上，用可见对象表达变化。Nana 视频包装 5.0 的图标汇入、签到联动、双窗口接力提供动作顺序。Nana 白板包装和华叔艺术动效提供逐笔揭示及「物在画面中完成动作」的方法。当前组件使用工作台的 Remotion 帧时钟。

| 原模板 | motionDetail | 可见动作 |
| --- | --- | --- |
| SideBeats | headline | 关键词两行落版，框线和底部笔画分两拍完成 |
| SideBeats | source | 开源符号逐笔出现，文字与信号线前后交接 |
| SideBeats | sources | 三种抽象来源沿同一条线翻入，可用于并列口播例子 |
| SideBeats | checkin | 开关拨动、签到格标记、筹码落入领取区、边缘确认光 |
| SideBeats | summary | 源头节点分出两个动作分支，后续文字按落点出现 |
| HubFlow | merge | 筹码沿输入轨汇入，输出入口逐次接收 |
| TechFlow | relay | 当前任务沿轨道移到下一节点，接收端点亮 |

在 plan.json 的 scene 顶层写 motionDetail，保留获批的镜号、布局、时间、主模板、摄像机与 SideBeats.props。每个动作从现有台词锚点起步。需要加限定时用可选 motionNote，文案取自本期素材和核对记录。未提供真实产品素材的画面标明「示意」。需要替换实际 B-roll、章节或镜头结构时按双审工作流更新分镜。

风格预览应覆盖动作前、动作进行中和动作完成后。汇入要检查筹码轨迹和接收点，签到要检查标记及领取状态，接力要检查同一个任务标识抵达下一节点。静帧之外可提供局部动态，给用户审节奏。全片渲染仍绑定该版本的风格确认。

签到托盘的描边随确认动作出现。把确认状态对齐原词，并在实帧检查边线与文字的对比。
