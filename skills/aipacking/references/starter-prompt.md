# 使用者启动提示词

请用 $aipacking 包装我上传的真人口播 MP4 和同版 SRT。如果还有截图、录屏或参考片，请区分哪些可以放进成片，哪些只作风格参考。

先完整读字幕，用 HyperFrames 给我一张逐段的分镜表：标清时间码、这一段的台词和画面目的、真人是保留还是收窗、哪里要加 B-roll、用什么原工作台模板和动效、对应哪个词入场，以及缺哪些素材。普通过渡不用堆特效，重点是让观众更快看懂。我确认分镜前，不做风格图，也不出片。

我确认分镜后，用原 Nana 使用者 Remotion 工作台的组件给我做 3–5 张实际预览，让我看开场、人物与动效同屏、核心图解或 B-roll，先定配色、版式和人物位置。保持原声原速和人物质感，不挡脸、不挡字幕，不用示意图冒充真实截图。

只有我确认这版预览后，再用同一套组件和分镜渲染整条 MP4。后续我只改某段时，只改对应片段；如果影响已审的分镜或风格，先给我看受影响的新版。

每镜请写明可见动作和台词触发词。普通口播保持稳定构图，选少数关键落点做看得见的轻推和回位，并在动态样片中展示。按语义切换已接入的侧边结构、真实证据、图解和原生模板。节奏由侧边对象分拍更新和图解推进承担，顶部显示从开头到片尾的章节进度。
