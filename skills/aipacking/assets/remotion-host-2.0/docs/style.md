# 主题：科技暗黑 + 体积光（tech-dark）

## 气质
深色底、体积光、玻璃质感、高对比大字。像科技发布会，不像 PPT。

## 颜色（只用这 6 个强调色，定义在 src/lib/theme.ts）
| 名称 | 色值 | 语义 |
|---|---|---|
| cyan | #5ee7ff | 默认、科技、理性、AI |
| violet | #8b7bff | 思考、未来、提示词 |
| pink | #ff6fd8 | 创作、人、情绪 |
| gold | #ffc94d | 结果、价值、钱、第一名 |
| red | #ff4d5e | 警示、错误、否定、印章 |
| green | #3be3b0 | 正确、真相、成长 |

## 背景（LightField，原创着色器）
| variant | 观感 | 适合 |
|---|---|---|
| prism | 全光谱放射，最炸 | 钩子、高光金句、结尾 |
| tunnel | 光速隧道 | 章节切换、时间线、技术 |
| rays | 顶光+光尘，大气 | 标题页、步骤、结论 |
| aurora | 极光幕 | 数据、百分比、温和段落 |
| silk | 丝绸流动，高级 | 引用、对比、观点 |
| nebula | 星云+星点 | 概念、宇宙感、悬念 |
| grid | 透视网格（无着色器，最快） | 图表、数据、界面展示 |

## 字体
- 中文：PingFang SC / 思源黑体 / 微软雅黑（系统自带即可），标题 900 粗。
- 数字与英文标签：JetBrains Mono / SF Mono / Consolas，英文标签全大写、字距 0.25em 以上。

## 动效语言
- 入场：字符逐个上浮+去模糊（Kinetic）、弹性缩放（pop）、玻璃卡片 3D 翻入。
- 强调：印章砸下（Stamp）、扫光（Shine）、数字滚动（CountUp）、边框光束（Glass beam）。
- 镜头：全屏页默认有 6% 的缓慢推近；3D 类页面有环绕。
- 转场：页面↔页面 缩放穿越/横推/翻转/擦除 轮换；页面↔人物 圆形揭开/白线擦除。

## 以后加新主题
复制 `src/lib/theme.ts` 为新主题并改色值/字体，背景在 `src/bg/LightField.tsx` 增加 variant。模板组件只引用 theme 和 accent()，换主题不用改模板。
