# 出片前自检清单

运行 `npm run qa` 后，打开 `qa/contact.jpg` 总览，再逐张看 `qa/` 里的单张。每张图都过一遍下面的问题，有一条不通过就修。

## 必须修（硬伤）
- [ ] **文字溢出/被裁切**：标题、卡片文字超出卡片或画面边缘 → 精简文字或调小 `size`。
- [ ] **挡脸**：叠加层盖住了人物的脸 → 换到另一侧或缩小。
- [ ] **压字幕**：视频自带字幕时，叠加层进入底部字幕区 → 上移。
- [ ] **元素互相重叠**（印章除外）→ 调整位置或时间。
- [ ] **空页面**：截图时刻页面上几乎没东西（元素的 `at` 太晚）→ 提前 `at`，或本页 start 往后挪。
- [ ] **数字/事实编造**：页面上的数字在文案里找不到 → 删除或标「示意」。
- [ ] **错别字**、中英文混排空格混乱。

## 应该修（审美）
- [ ] 连续两页长得很像（同模板/同背景/同颜色）。
- [ ] 一页上字太多（> 4 个要点，或整句口播原文上屏）。
- [ ] 高光句没有给到强页面。
- [ ] 颜色太花（一页超过 3 种强调色）。
- [ ] 某一段全屏页连续超过 12 秒没有人物出现（除非用户要求少露脸）。

## 修完之后
- 只重跑改过的场景：`node scripts/qa.mjs s05 s12`
- 最多三轮。三轮后仍有问题，出片并在结果里告诉用户哪里还不完美、建议怎么处理。
