# 视觉规范（硬性规则）

这份文件是所有模板和分镜都必须遵守的底线。每一条都有对应的自动检查，`npm run validate`（分镜）和 `node scripts/lab.mjs`（模板体检）会拦下违反的情况。

## 1. 文字必须看得清（对比度）

- **大字（≥24px）对背景至少 3:1，小字（<24px）至少 4.5:1**（WCAG 标准）。体检会读出截图里每段文字周围的实际像素来算。
- **字色由它正下方的底色决定，不是由主题决定。** 深色底用浅色字，浅色底用深色字。按钮、标签、气泡、头像、色条、卡片上的字，一律用 `onColor(底色)`，不要写死 `var(--ink)`、`#fff`、`#111`。渐变底传两端颜色：`onColor([a, b])`。
- 主题的三档文字色：`--ink`（主文字）、`--ink-dim`（次要）、`--ink-faint`（淡色）。三档都保证对主题背景至少 4.5:1，改主题背景色时要重新算（见 `src/lib/theme.ts` 注释）。
- SVG 文字要写 `fill`，不写的话默认是黑色，暗色主题下会看不见。

## 2. 视觉禁区（用户明确不要）

- 射线、镭射、光谱放射、光速隧道类背景（`rays` / `prism` / `tunnel`）。代码里写了也会被自动换掉，分镜里写了校验会报错。
- 漂浮的气泡、玻璃球。
- 糖果色、表情、低幼元素。
- 人像保持原色，禁止黑白或单色滤镜。

## 3. 字号和排版

- **不要把屏幕塞满。** 一页的文字面积不超过画面的 30%，单个字高一般不超过 260px（装饰性的巨型字除外）。
- **放不下就自动缩字，不许冲出画面、不许被裁切、不许折行压到别的元素上。** 模板里所有会上屏的文字都要用 `fitSize()` / `fitLines()`（`src/lib/fit.ts`）按所在区域的宽度计算字号，并设 `whiteSpace: 'nowrap'`。
- 中文最小 16px。
- 列表、卡片类模板要按实际数量均分宽度（比如 2~4 张卡片都要放得下），不能按写死的间距排。

## 4. 安全区

- 底部 150px 是字幕区，叠在人物上的元素不能进入（视频自带字幕时）。
- 叠加层不能挡脸。

## 5. 动效

- 页面在「中段」（时长的 60% 处）所有元素都要出齐，不能是空页。
- 每个模板都有**最短时长**（写在规格卡里），比这更短动画播不完，校验会报错。
- 完全滑出画面的文字属于动画设计（滚动墙、横移镜头），允许；一半在画面里被切掉不允许。

## 6. 装饰元素

背景里的大号水印数字、巨型问号这类装饰，给元素加 `data-probe-skip` 属性，体检时不当正文文字检查。印章类故意盖在文字上的效果也这样标记。
