# 节奏、构图与声音

来源：用户2026-10-12提供的133.8秒参考片；已看全片1fps抽帧和重点5fps序列，结合字幕与剪辑时间轴研究。声音结论来自混音波形和片中演示，未确认独立音效音色或插件参数。提炼经用户批准。示例区间：0–6秒文字与动作开场；7–28秒动作蓄力/曲线变速/HIT；43–73秒音乐分段与停顿；89–98秒快切后停住；119–133秒动作衔接与拼贴。它们是选择依据，不是所有视频都要照搬的模板。

## 编导

本用户要求开头3秒用当前能做到的最强效果。开头单独执行 `opening-impact.md`，将最高视觉设计投入放在0–3秒；后续普通解释再采用下述轻重交替。不开场先裸口播、等正文才出现高光。声音可配合开场高潮，但无真实音效时必须明确未制作，不能靠提高音量替代视觉动作。

逐句分析之外，按完整表达单元写「预期 → 蓄力 → 揭示 → 稳定停留」。选择最值得强调的结论或结果，普通解释保持轻包装。音乐不能决定知识内容的切点；优先口播语义，再配音乐。素材、文字和声音在同一高光落点同步，落点后保留阅读时间。

动作蓄力可先减少画面变化，再快速建立结论；快切案例之后停在结果。时间参数按内容调节，可从0.15–0.35秒蓄力、0.1–0.2秒建立、1.2–2秒停留试起，均为新设计起点，非原片实测。截图与详细数字需要更长停留。用户已允许在句间创造留白、穿插片段，必要时小幅加速内容。需要调整时先生成新的剪辑时间线及重映射后的SRT，并实查声画同步；不得截断词句或冻结正在说话的嘴部。未实施重映射时保持原口播时钟。曲线变速/停格只用于图卡、案例或操作素材。

## 构图组件

- `TechImpact`：人物大窗、左侧倾斜关键词、右侧前景素材图卡，短促的落点脉冲后归稳；无需伪造人物抠像。最短3秒，title至多两行，media 0–2项。媒体可能与人物窗边缘有少量叠放，检查面部不被遮挡。
- `TechCollage`：默认stack为大人物画面+错位素材图卡，依语义错峰入场后停住；mode:diagonal用3份素材形成斜切拼贴，人物独立显示。最短4秒，title单行，media 1–3项，diagonal必须3项。stack的第3项小图卡是前景强调，若文字/完整界面需要阅读，改为2项布局。斜切模式只用于风格/动作素材，不裁切需要读完整的证据截图。
- `TechMontage`：相同素材窗口内切换2–4个真实素材，在holdAt指定的时刻暂停材料时钟，再继续；真人与口播始终同步。最短4秒。cutEvery默认0.55秒，仅适合风格示例/动作素材；信息截图不能用默认快切。holdDuration默认1.2秒。匹配剪辑需有相近构图/动作的素材，不能把普通换图称为动作匹配。

共同props：preset、title、kicker、note；media为`{src,kind:'image'|'video',offset?:秒,label?,at?:绝对秒或关键词,fit?:'contain'|'cover'}`。每段video offset及本场景时长须在素材范围内，不能无提示循环。默认contain保留真实截图完整内容。标题titleAt、落点hitAt、暂停holdAt使用本工作台关键词锚点。Montage的暂停只作用于素材，不作用于人像和字幕。

人像保持原色；底部150px留给字幕。参考中的模糊、色边、震动、黑屏只按高光考虑，不变成全片默认。长黑屏不是口播的默认蓄力手段。实拍动作、光线、前景遮挡依赖原素材，不能宣称纯包装可以复刻拍摄条件。

## 声音

为高光编排一条声音时间线，区分口播、配乐、短音效。保留连续原口播；配乐让路，揭示前的降低/留空只作用于配乐；HIT只服务少数明确落点。若需要更柔和表达，用轻提示音而不是重击。不要给每张卡片都加相同音效。

所有音乐/音效须有真实本地文件和可追溯的授权来源；不提取参考片音乐冒充可用素材。没有合适声音时保留原口播，并报告声音层未制作，不把示意提示音作为生产素材。

可在plan.json新增可选audio字段：
```json
{"audio":{"music":{"src":"audio/music.mp3","gainDb":-24,"start":0,"duck":[{"start":10,"end":11,"gainDb":-12}]},"cues":[{"src":"audio/hit.wav","at":11,"gainDb":-16}]}}
```
数值是试混起点，不是固定响度标准。确认语音清晰、无削波、配乐退让和落点同步；不能只凭音轨数量或导出完成声称听感通过。`scripts/mix-audio.mjs <工程> <已渲染MP4> <新输出MP4> --check`先验证本地音频与时间，再不带--check实际混音；原成片不覆盖。没有audio配置则不改音频。duck字段的gainDb是相对music主音量的衰减值，边缘短渐变防止突兀，cues at为绝对秒，导出前从语义锚点换算。

## 检查

除原QA外，检查蓄力之前、落点±几帧、归稳之后、素材快切/暂停恢复；截图阅读、脸和字幕安全区、口型同步、音乐/音效落点分别核对。记录静帧、实际导出与连续听看检查层级。首次新增构图用独立短样例验证，不重导已交付历史视频。
