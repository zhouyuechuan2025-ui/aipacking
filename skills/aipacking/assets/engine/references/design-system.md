# 配色、版式与运动

## 配色

|预设|背景|文字|主色|辅助色|点睛色|适用|
|---|---|---|---|---|---|---|
|violet-tech|#E8E7F8|#29264F|#5750D9|#067D8B|#A13C58|AI工具、产品发现，默认|
|cyan-data|#DDF0ED|#193D45|#006D70|#6954CA|#AE5129|数据、流程、效率|
|warm-tech|#F5EAD8|#49332F|#A54B33|#4666BF|#866718|商业、知识分享、大促科技感|
|gallery-light|#F3F1FA|#201D32|#6342C7|#007477|#A13361|浅色讲解、艺术编辑、专业清爽|

这是本 skill 的设计选择，不是参考品牌的官方配色。渐变只做背景弥散、边缘或小面积形体；正文用稳定字色，不放在明暗高速变化的底色上。多色要有角色：主色标结论，辅助色标过程，点睛色标结果或关键动作。中性色仍占大部分面积；同屏通常不超过三种强调色。该分配是默认设计判断，可按题材调整。

## 更丰富的画面

- 三个深度层：低对比背景纹理/弥散光，清晰的内容面板，少量前景强调。背景允许缓慢漂移，正文保持稳定。
- 三种增强全屏模板：`TechHero`（非对称开场与抽象界面）、`TechBento`（一大多小的语义卡片）、`TechFlow`（输入到输出的连接与流动）。真实操作演示用真实截图或录屏，不把抽象卡片冒充软件界面。
- 在开场、流程、数据、引用、真实素材和结论之间切换结构；避免连续三页只是换颜色的居中文字。不用固定模板数逼迫短视频频繁切页。
- 先确认原句需要什么表达；标题一般≤8中文，要点≤12中文，单页2–4点。文字装不下就精简或拆页，不以极小字塞满。
- 人物出场由内容决定，不设最低露脸比例。完整口播、设计窗口、全屏资料/案例/图解、人物回归交替；人物显示时避开脸与字幕，离场时资料可完整接管。

## 动效组织

以下轻动作预算适用于普通正文。开头0–3秒遵循 `opening-impact.md` 的强开场规则：在一条清楚的主动作链上组合前后景、完整窗口变化、语义对象转化等效果，并快速归稳；不能用正文的轻包装强度处理开头。冲击力来自尺度、层次、动作与停顿，不能用多种无关装饰、重复闪烁或标题遮脸替代。

一页有一个主动作：文字遮罩揭示、卡片建立、路径连通或结果突出，选其一。配一两个轻动作：标签错峰出现、边缘色线、低速背景漂移。网页 hover/scroll 只作为设计参考，视频改成确定的帧号或原稿关键词锚点。

推荐初始参数：主动作0.35–0.65秒、次级错峰0.08–0.14秒、离场0.2–0.35秒。关键词同步出现后保留阅读时间，结论尽量≥1.5秒。高光场景允许更明显的景深或轻微透视；日常正文避免循环抖动、全屏闪白和频繁故障效果。时长太短则减少元素和动效，不能抢跑无关事实。

增强页中段应完整可读。动态延迟 `at` 是绝对秒或 SRT 关键词；不要同时加长错峰把关键文字推到页尾。

## 增强模板字段

共同：`props.preset`（上述预设名）、`kicker`（短标注）、`title`（Hero/Bento标题）、`titleAt`（可选锚点）、`note`（短说明）、`noteAt`、`items`（最多4个）。`layout` 必须为 `full`，由主工作台重绘覆盖的字幕。

- `TechHero`：建议3秒以上；`title` 支持字符串数组（最多两行），`items` 为最多3个短词；右侧只是概念图，默认标“概念示意”。
- `TechBento`：建议4秒以上；`items` 为2–4个 `{title, body?, at?}`；第一张大卡突出结论。
- `TechFlow`：建议4秒以上；`items` 为2–4个 `{title, body?, at?}`；节点连接、流动指示及结果保持同一方向。

旧模板须单独检查硬编码纸白/墨色。此增强没有改写所有旧模板，也没有把新的调色板注入旧 `theme.ts`。侧边页仍可复用 `SideCard` 与 `SideBlocks`，按 `main` 设主色，实查人像与文字位置。

## QA

使用原稿真实最长词和真实条目数检查，避免只看短示例。确认背景最亮/最暗阶段仍能读到正文，正文对其实际底色≥4.5:1，≥24px大字至少3:1。渐变背景上的细字用实色承载面板。查中段、进出场、第一帧和最后帧；完整播放另查节奏、音画同步、突闪和过度运动。记录抽帧与播放分别是否完成。

出片检查沿用原工作台。丰富感以结构、节奏、色彩层级和素材变化实现，不以装饰数量衡量。

## TechPresenter 真人画面

`layout: full`，最短1.8秒，`showsPerson: true`。`props` 包括 preset、mode、title（最多两行）、titleAt、focusAt、kicker、detail、words（最多三个 `{text, at}`）。支持 push / focus / float / process / final 五种模式。原片窗口参与构图，面部保持原色，镜头推进与语义关键词同步。流程页只保留原稿已提及的节点。不要靠高频缩放提高丰富度。
