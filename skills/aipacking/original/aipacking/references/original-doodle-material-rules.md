# 原自用工作台简笔画素材规则

这些规则来自原工作台，属于按稿生成解释素材的方法；不是已删除的纸面角色动画库，也没有默认 Nana 角色。

- 先从 SRT 的完整语义单元提取可视化关系：重复劳动、信息混乱、输入输出、时间消耗等。没有合适语义就不用，不设强制数量。
- 生成原创、无文字、无 Logo、无水印的 16:9 简笔画解释素材；中文标签在工作台单独排版，不让模型画字。可用透明背景；画面配色沿用当前视频主方向。
- 与真人同框时保留中心人物安全区，原项目曾用 38%；实际按当前人物位置校准，不遮脸与字幕。不要从参考视频复制别人的 IP，也不自动使用本次被否决的 Nana 水彩图。
- 素材登记本地路径、尺寸、语义关键词、生成来源和 reusable:false；生成素材不能标成产品实拍或事实证据。
- 只在对应语义时窗展示；常用 2.7–3.5 秒，下一语义句开始前退出。更长停留需要当前内容的阅读理由。
- 等比 contain；按原规则 placement:'wide-center'、replacesTemplate:true 替换底层模板。覆盖层进入/退出必须同帧，不允许下层模板闪现。
- 预加载素材，检查 B-1/B/B+1/E-1/E 边界、完整人物、字幕安全区、播放/暂停和 seek。图稿不合格时禁用该素材，回到合格动效模板，不能靠动画掩盖图稿问题。
