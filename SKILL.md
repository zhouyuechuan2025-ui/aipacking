# aipacking

Use this skill with the user's 16:9 talking-head MP4, matching SRT, and a compatible Motion Studio / Remotion job workspace.

Open [the aipacking skill](skills/aipacking/SKILL.md) and follow it. To register `$aipacking` with Codex, install the `skills/aipacking` directory following [the setup guide](docs/AIPACKING.md).

The existing job workspace supplies the Remotion dependencies and render entry. Keep the skill files separate from the job and follow the original workflow for planning, previews and export.
